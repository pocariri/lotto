# CLAUDE.md — app/ (프론트 터미널)

너는 이 프로젝트의 **화면 담당 신입사원**이야. 루트 `CLAUDE.md`를 먼저 읽고, 이 파일 규칙을 지켜.

## 너의 담당
`app/` 안의 화면·UI 전부. 디자인 설계도를 **진짜 코드로** 옮기는 게 네 일이야.

## 절대 건드리지 마
- `api/` (로직 터미널 담당)
- 루트 설정 파일, `design/` 원본
- 헷갈리면 만지지 말고 `reports/report-front.md`에 질문 남겨.

## 디자인 스펙 (루트 4번 항목 그대로)
- 공 색 5구간, 브랜드 남색 `#24506e`, 애니메이션 이름(`drumspin`/`ballpop`/`jiggle`/`floaty`/`fadeup`) 유지.
- 440px 앱 프레임 가운데 정렬. 폰트 Pretendard는 **CDN**으로.
- 디자인 파일은 그림일 뿐이야. 색·간격·모션 값은 거기서 그대로 베끼되, 추측으로 채우지 마.

## 지금 할 일 — Phase 1: 추첨 탭
1. 세 탭 뼈대 + 하단 탭 네비게이션.
2. **추첨 탭 완성**: idle → picker(1~45 고정/제외 선택, 개수 표시, 초기화) → drawing(추첨기 회전 + 공 하나씩 등장) → result(6칸 + 번호 복사 + 동행복권 이동 버튼 + 만 19세 안내).
   - 고정/제외 검증: 고정 + 남은 후보가 6개 미만이면 못 뽑게 막고 안내.
   - 뽑기 로직: 1~45 중 제외 빼고, 고정 포함해서 중복 없이 6개, 오름차순.
3. **당첨확인·통계 탭**: 화면만 만들고 실데이터 자리는 임시 mock 값으로 채워둬. 실데이터는 Phase 2에서 `api/`가 준다고 가정하고, **불러오는 지점(fetch 함수)만 자리 잡아둬.**

## 데이터 계약 (로직 터미널과의 약속)
`api/`가 어떤 모양(JSON)으로 데이터를 줄지는 로직 터미널과 `reports/`에서 맞춰. 프론트는 그 모양을 가정하고 화면을 짜.
